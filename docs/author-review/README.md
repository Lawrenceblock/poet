# 作者审阅材料（docs/author-review/）

面向**作者本人**的诗歌候选审阅材料。由 `tools/author-review/build_author_review.py`
从**只读**的 `docs/poetry-discovery/poetry-candidates.v2.csv`（137 条）生成。

## 文件清单

| 文件 | 说明 |
| --- | --- |
| `2026-11-12-poetry-candidate-review-guide.md` | 总览报告（普通中文，解释来源与分类） |
| `poetry-candidates-author-review.csv` | 完整候选审阅表（每篇文章一行，可填确认结论） |
| `batch-A.md` | A 类 104 条，手机可读 |
| `batch-B.md` | B 类 31 条，手机可读 |
| `batch-CD.md` | C/D/E 类 2 条，手机可读 |
| `2026-11-12-priority-review-recommendations.md` | 第一批优先审阅建议 |
| `2026-11-12-work-boundary-notes.md` | 作品边界问题说明 |

## 重新生成

```bash
python3 tools/author-review/build_author_review.py
```

脚本**只读** v2 CSV，**不修改**任何原始数据，**不复制**诗歌全文
（仅复用 v2 CSV 中已存在的**截断摘录** `note`）。

## `poetry-candidates-author-review.csv` 字段说明

| 字段 | 含义 |
| --- | --- |
| `序号` | 审阅序号（1–137） |
| `candidate_id` | 与 v2 CSV 对应的**文章级**候选 ID |
| `原始文章日期` | 原文发布日期 |
| `文章标题` | 原文标题 |
| `原始文章URL` | 原文链接 |
| `当前分类` | A / B / C / D（**脚本判定，非作者确认**） |
| `分类含义` | 分类的中文解释 |
| `分类依据（脚本）` | 脚本命中该类的具体证据 |
| `是否有结构化作者署名` | yes/no，是否检测到署名结构（如 `文/安然`） |
| `是否出现作者姓名或笔名` | yes/no，标题或摘录中是否出现“安然” |
| `是否可能存在译者身份` | yes/unknown，是否有译者线索 |
| `是否有组诗或多首作品线索` | yes/unknown，标题是否含“组诗/外一首/二首”等 |
| `当前作品数量估计` | `>=2`（有明确多首标记）/ `unknown`（无标记，**不假定为 1**） |
| `需要作者确认的问题` | 该行**最关键**的一个待确认问题 |
| `作品边界问题` | 关于“一篇文章含几首诗”的待确认问题 |
| `作者确认状态` | **初始恒为**“待作者审阅”，由作者填写 |
| `备注（脚本，截断摘录）` | 用于定位的**截断摘录**（**非全文**） |
| `语言` | zh / zh+en / en |
| `置信度（脚本）` | 脚本置信度（0–1） |
| `source_post_id` | 旧博客文章 ID |

## 重要声明

- 本目录**不含**任何“作品归属结论”，**不拆分**任何作品。
- **137 条是文章级候选记录，不是 137 首诗**；独立作品总数**尚未确定**。
- `作者确认状态` 初始一律为“待作者审阅”，**不会**被程序改写为结论。
