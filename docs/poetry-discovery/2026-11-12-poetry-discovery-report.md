## 1. 调查范围

- **对象**：安然自 2008 年起持续写作的个人博客 `https://www.ismaelan.com/`。
- **目标**：尽可能完整发现散落在历年博客文章中的诗歌作品，建立可检索、可核对、可持续补充的索引。
- **边界**：只读调查。**未修改旧博客任何内容**，**未批量复制诗歌正文**，**未将任何候选作品发布到新网站**。

**《青春的物语》版本差异（**【已验证事实】**）**：
- **博客版**：纯文本 + 换行，署名 `文/安然`；英文 `Youth's Tale / by An Ran`。
- **站点版**：手工 HTML（`<div class="poem">` + `<br>` + 内联 `text-align`），含字面 `**Youth's Tale**`、`*by **An Ran** *`、字面 `---`。
- **性质**：站点版是博客版的 **HTML 化改写**，引入**未渲染的 Markdown 符号**（与审计报告一致）。两版**文字内容基本一致**，**排版标记不同**。
- **处置原则（建议）**：**不得**用任一版覆盖另一版；迁移时**保留两版**、标注差异，交作者确认。

## 7. 自动识别方法与准确性

### 7.1 方法（**【自动识别】**）

1. **获取**：Blogger JSON Feed 分页抓取 305 篇全文 HTML。
2. **提取**：HTML→文本（`<br>`/`</p>` 转换行，去标签，`html.unescape`）。
3. **诗歌信号**：`诗歌` 标签；标题含 `诗/詩/组诗/歌/吟/谣/赋/诗话`；**诗行结构评分**（短行 ≤30 字占比 ≥0.6 且行数 ≥8）。
4. **分类**：D（标题含 `诗话/创作谈/诗论/评论/序言/赏析`）→ C（“安然-as-translator”或英文 `Translated by`）→ E（`转载/摘自/引自/原作:` 且无署名）→ A（明确署名 `文/安然`、`安然/文`、`/安然`、`by An Ran`，或“诗歌标签+诗歌标题关键字”）→ B（有诗歌信号但无署名证据）。
5. **多首标记**：标题含 `两首/二首/三首/组诗/外一首`。

### 7.2 准确性验证（**【已验证事实】**）

- **已知线索召回率 8/8 = 100%**。
- 人工抽查：`一篇诗话`→D ✅；`Home`→C ✅；`致被盗走的新月`→A ✅（中文安然原创，英文由 Hendan 译）；`两首格则勒`→确含两首 ✅。

### 7.3 局限（**【无法确认】/【待人工审核】**）

1. **作者归属靠正则**：无署名但确为安然的诗判 B；有署名但实为引用者可能误判 A。
2. **E 类可能被低估**：脚本对“引用标记 + 有安然署名”判 A。
3. **多首诗拆分**：仅靠标题标记，正文内嵌多首**无法自动拆**。
4. **诗歌边界**：文章含“诗 + 长散文 + 后记”时整篇算一个候选，边界不准。
5. **`work_title` 字段**：仅当标题含诗歌关键字时填入，其余为空。
6. **创作时间缺失**：Feed 仅发表时间。
7. **B 类 29 篇**：**全部需人工阅读确认**。
8. **翻译类**：仅识别 1 篇 C，旧博客可能仍有未标注的翻译诗。

## 8. 主要问题

1. **【已验证事实】** 诗歌大量存在于**无 `诗歌` 标签**的文章中，仅靠标签会**漏检**。
2. **【已验证事实】** 存在**中英双语**诗歌，英文可能是自译或他人译（如 Hendan），**归属需逐篇确认**。
3. **【已验证事实】** 部分文章**一稿多形态**（博客纯文本 vs 站点 HTML），存在**版本差异**。
4. **【推断】** 站点《那拉提（未赴）》《诗人小传》**未见于博客**，可能为 2026-08 后新作，**待作者确认**。
5. **【已验证事实】** 存在多首诗合并在一篇的情况，**边界需人工拆分**。

## 11. 未来迁移建议

1. **只迁移经作者确认的作品**，**不批量迁移候选**。
2. 迁移时**逐字保留原文**（标点、分行、空行、标题、署名），**不得润色**。
3. **双语作品**中英两版**分别保存**，注明译者。
4. **版本差异**（如《青春的物语》）**保留多版本**，标注来源，不覆盖。
5. **URL 兼容**：见 `docs/migration/url-compatibility.md`。
6. **候选清单只记元数据**，正文在作者确认前**不进入新站点**。
