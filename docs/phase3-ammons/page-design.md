# Phase 3 · 页面设计说明（Page Design）

> 依据 `research.md`（参考研究）与 `design-system.md`（视觉规范）。
> 逐个说明主要页面的**设计意图、版式、非对称手法、移动端**。
> 标注：**【建议】** 本轮方案；**【约束】** 不得违反的硬性要求。

---

## 0. 全局骨架（baseof）

```
┌──────────────────────────────────────────────┐
│  黑色顶栏（窄）：站名（左） · 导航（右）        │  ← 高度小，非"标题条"
├──────────────────────────────────────────────┤
│                                              │
│   纸白主区（--paper）                          │
│   · 首页：黑主视觉 + 非对称内容块              │
│   · 诗歌页：黑色页头窄带 + 纸白正文             │
│   · 索引/说明：纸白 + 大字号层级               │
│                                              │
├──────────────────────────────────────────────┤
│  黑色页脚（结构节点）                          │
└──────────────────────────────────────────────┘
```

- **【建议】黑色顶栏**：不再是「等宽黑标题条」，而是一条**窄的黑色横带**，
  站名与导航在同一行的两端（桌面），窄屏折叠为两行。
- **【建议】页脚**：黑色，承接参考项目「黑色作为结构节点」的语言；
  内容为站名 + 栏目索引 + 版权。
- **【约束】** 不新增依赖、不引入远程字体、不改内容。

---

## 1. 首页（`layouts/index.html`）

### 设计意图
参考 Ammons 首页的**非对称构图 + 大标题 + 黑块配重**，但转化为中文诗歌档案。

### 版式【建议】
```
┌──────────────────────────────────────────────┐
│  黑 色 主 视 觉（整块黑，约首屏 60–72vh）        │
│  ┌───────────────┐   ┌──────────────────────┐ │
│  │ 大字号身份     │   │  封面图（可选，黑白）  │ │
│  │ 安然           │   │  /assets/img/cover.png│ │
│  │ ANRAN · ARCHIVE│   └──────────────────────┘ │
│  │ 一句话副题      │                            │
│  └───────────────┘                            │
└──────────────────────────────────────────────┘
   ↓ 纸白
   ┌ 左窄(5) ───────────┐ ┌ 右宽(7) ──────────────┐
   │ 最新作品（列表）     │ │ 按年份（大号年份块）    │
   └────────────────────┘ └───────────────────────┘
   ┌ 左宽(7) ──────────────────────┐ ┌ 右窄(5) ──────┐
   │ 栏目入口（大字号链接）          │ │ 说明（小字）    │
   └───────────────────────────────┘ └──────────────┘
```

- **非对称**：内容块宽度在 5/7 与 7/5 之间**交错**，左右留白不等。
- **大标题**：站名用 Display 级字号（中文宋体大字号 + 宽字距），
  英文 `ANRAN · POETRY ARCHIVE` 作小标签对照。
- **【建议】** 主视觉左对齐（桌面），窄屏改为上下堆叠、文字在上、图在下。
- **【建议】** 「按年份」区块用**大字号年份 + 作品数**，不用圆角胶囊标签。

### 移动端
- 主视觉改为纵向：身份文字 → 封面图；字号自动缩小（`clamp`）。
- 内容块**全部单列堆叠**；年份区用横向可换行的大号年份。
- 触控目标 ≥ 44px。

### 内容来源（不改动）
`index.html` 现有数据（`.Site.RegularPages Section=posts`、封面 `coverImage`、
`enableReview` 开关）**全部保留**，仅重排版式与样式。

## 2. 诗歌正文页（`layouts/_default/single.html`）★最重要

### 设计意图
参考项目「诗歌页 = 深色起始屏 → 明亮正文」的对照。本站无手稿素材，
转化为：**黑色页头窄带（标题 + 元信息）→ 纸白正文（最大化留白）**。

### 版式【建议】
```
┌──────────────────────────────────────────────┐
│ 黑 色 页 头（窄）                              │
│   诗歌标题（H1，大字）                          │
│   作者 · 创作日期 · 语言（小字，分层）           │
├──────────────────────────────────────────────┤
│                                              │
│            纸白正文区（--measure-poem）         │
│            诗歌正文（保留分行/空行，逐字不变）    │
│                                              │
│  ─── 细线 ───                                 │
│  题注 / 说明（若有，小字）                      │
│                                              │
│  ← 卷目                                        │
└──────────────────────────────────────────────┘
```

- **【约束】诗歌正文逐字不变**：模板只改变**包裹容器与样式**，
  `.Content` 输出的 HTML 与文本**不得被改动**。`{{< poem >}}` 短代码
  与 `white-space: pre-wrap` 逻辑保持不变。
- **【约束】** 不改动 `hugo.toml` 中与内容/路由相关的既有配置；不改 front matter。
- **【建议】** 正文区居左或沿用居中（沿用现状：`.poem-content` 居中，
  英文左对齐）；行高 2.3 保持。
- **【建议】** 元信息（作者/日期/语言）在黑色页头内以**小字、加宽字距**排列，
  与标题形成强尺度对比（对照参考项目的「日期标注」）。
- **【建议】** 页头黑色为**窄带**（非满屏），正文纸白面积最大化。

### 移动端
- 页头压缩内边距，标题自动换行、字距略减。
- 正文阅读宽度自适应，行高保持 2.3，左右内边距 ≥ 1.15rem。

## 3. 卷目 / 年代索引（`archive.html` / `years.html`）★重点

### 设计意图
参考现代文学刊物的**目录设计**：大字号年份、细线、编号、层级分明。

### 版式【建议】
```
┌ 左窄(4) ──────────┐ ┌ 右宽(8) ─────────────────────────┐
│ 20 26             │ │ 03 · 那拉提的雨            2026.09 │
│ （大号年份）        │ │ ────────────────────────────────  │
│ 3 篇              │ │ 11 · 2026 年的雪           2026.11 │
│                   │ │ ────────────────────────────────  │
│ 20 19             │ │ 04 · 组诗 · 三首短歌        2026.04 │
│ ...               │ │ ...                               │
└───────────────────┘ └───────────────────────────────────┘
```

- **【建议】大字号年份**（Display 级）作左侧锚点；右侧作品列表用**编号 + 标题 + 日期**。
- **【建议】细线分隔**（`--rule`），**不用卡片、不用彩色**。
- **【建议】年份之间用大留白**（非密集），形成「年代分隔」。
- 作品数用 `--muted` 小字，不用胶囊标签。
- **【约束】** 列表数据与 URL 不变（`GroupByDate`、`RelPermalink`、锚点 `#year-YYYY` 保留）。

### 移动端
- 年份块变为**横向大号标题行**，作品列表在其下缩进；年份可做吸顶（可选）。

## 4. 作者介绍页（`shi-ren-xiao-zhuan`，`layout: about`）

### 设计意图
参考 Ammons 人物专题：标题 + 照片 + 文字 + 留白。本站暂无照片与授权传记文字。

### 版式【建议】
- 顶部：大字号标题「诗人小传」+ 英文小标签。
- 正文：`prose` 左对齐、行高 2.0；章节标题（`h2`）**改为大字号左对齐标题**，
  **不再用 Phase 2 的黑色标题条**（改为：标题 + 上方细线 + 大留白）。
- **【建议】** 预留一个**可选肖像位**（`static/assets/img/portrait.*`）：
  有图则黑白处理、3:4，与文字非对称并置；**无图则纯文字**，不留空框。
- **【约束】** 不编造任何作者经历、获奖、评价；正文占位内容保持原样。

---

## 5. 档案与版本记录页（`about`，含档案原则）

### 设计意图
借鉴出版社/艺术机构/数字人文档案的**严谨编辑排版**：编号、层级、可读。

### 版式【建议】
- `h2` 用「编号 + 标题」形式（如「一 · …」），左对齐，字号中上，上方细线。
- 列表用**悬挂缩进 + 细线**，数字对齐；弃用卡片。
- 长文行高 2.0，段间距 1.1em；引文用左侧细线（`--accent` 2px）区分。
- **【约束】** 不改动档案记录、编号、版本关系与安全控制。

---

## 6. 题记（`preface`，`layout: preface`）

### 设计意图
单篇文学文本的**安静阅读页**：大留白、宋体、无装饰。

### 版式【建议】
- 顶部大字号标题 + 细线；正文纸白、行高 2.05、左对齐。
- 落款（`.sign`）右对齐、`--muted`。
- **【约束】** 不复制、不改写旧站题记文字；占位内容保持原样。

---

## 7. 搜索页（`search.html`）

### 设计意图
功能页也纳入编辑体系，但**功能逻辑不变**。

### 版式【建议】
- 大字号「搜索」标题 + 细线。
- 输入框：**下边框式**（去掉方框感），聚焦时下边框转 `--accent`；
  或保留细边框但更克制（`--rule-strong`，无圆角、无阴影）。
- 结果列表沿用「标题 + 日期」的细线列表。
- **【约束】** `search.js`、`/index.json`、`data-baseurl` 逻辑**不动**；
  `#search-input` / `#search-status` / `#search-results` 的 id 与结构**必须保留**。

---

## 8. 404 页

- 大字号「404」+ 一句说明 + 返回首页/卷目链接；纸白、留白充分。

---

## 9. 审阅页（`/review/*`，由 `serve_review.py` 提供）

- **【约束】审阅页不在 Hugo 构建内**，其样式来自 `tools/author-review/build_review_site.py`
  生成的内联 CSS。
- **【建议】本轮可同步更新审阅页的视觉**（仅外观，不动数据/字段/API），
  使其与公开页风格一致；**但安全门禁（令牌）逻辑完全不动**。
- **【约束】** 无论是否调整外观，`/review/` 无令牌/错令牌/空令牌必须仍返回 401。

---

## 10. 移动端统一规则

1. 桌面非对称双栏 → **单列堆叠**（图像在上，文字在下）。
2. 中文大标题**允许换行**，字号随 `clamp` 缩小，字距相应调整。
3. 导航收敛：窄屏两行或横向可滚动。
4. 诗歌正文阅读宽度受控（约 20–24 汉字/行），行高 2.3。
5. 触控目标 ≥ 44×44px；长列表保持节奏（区块间 3rem 留白）。

---

## 11. 本轮不做的事（边界）

- 不改 `hugo/content/**` 诗歌原文、作者小传、题记、档案记录。
- 不改 `hugo.toml` 中与内容/路由相关的既有配置。
- 不改审阅记录、审阅系统安全逻辑、令牌机制。
- 不改正式域名、DNS、正式部署配置。
- 不复制 Ammons/Tubik 的任何照片或商业素材。
- 不合并任何 PR、不动 `main`、不动 Phase 1/2 分支与成果。
