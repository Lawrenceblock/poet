# Phase 3 · 视觉规范（Design System）

> 依据：`docs/phase3-ammons/research.md`。本文件把 Ammons/Tubik 的编辑设计语言
> 转化为「安然诗歌档案」可执行的设计变量与规则。
> 标注约定：**【事实】** 已核实；**【推断】** 基于图像的判断；**【建议】** 本站方案。

---

## 1. 设计原则（五条）

1. **黑为骨，白为诗**：黑色只出现在结构节点（首页主视觉、诗歌页页头、页脚）；
   其余为纸白，让诗歌在最大留白中呼吸。
2. **层级靠字号与字距，不靠颜色与装饰**：弃用卡片、阴影、圆角、彩色标签。
3. **创造性非对称**：不等宽栏、黑块配重、标题可跨栏；避免居中卡片堆叠。
4. **负空间即分隔**：区块之间用空白分隔，而非边框与背景块。
5. **温度来自摄影，不来自界面配色**：界面为无彩色；若用照片则做黑白/低饱和处理。

## 2. 色彩变量

### 2.1 变量表【建议】

```css
:root {
  /* 纸面 */
  --paper:        #FAF9F7;  /* 页面主背景（暖白） */
  --paper-2:      #F2F1EE;  /* 次级底 / 浅灰区块 */
  /* 墨色 */
  --ink:          #141414;  /* 主文字 */
  --ink-2:        #4A4A4A;  /* 次级文字 */
  --muted:        #6B6B6B;  /* 辅助文字（日期/编号） */
  /* 结构黑 */
  --black:        #0E0E0E;  /* 黑色空间区（主视觉/页头/页脚） */
  --on-black:     #F2F1EE;  /* 黑底主文字 */
  --on-black-2:   #A8A6A2;  /* 黑底次级文字 */
  --on-black-3:   #8A8885;  /* 黑底最弱文字 */
  /* 线 */
  --rule:         #DAD8D4;  /* 细分隔线 */
  --rule-strong:  #C4C1BC;  /* 稍强线 / 输入框边 */
  --rule-on-black:#2A2A2A;  /* 黑底分隔线 */
  /* 强调（极克制） */
  --accent:       #7A2A34;  /* 暗红：链接/当前项（白底） */
  --accent-on-black:#C98A92;/* 暗红衍生（黑底可读） */
}
```

### 2.2 用途与对比度【事实：实测 WCAG 对比度】

| 前景 | 背景 | 比值 | AA（正文 4.5:1） | 用途 |
|------|------|------|-------------------|------|
| `--ink #141414` | `--paper #FAF9F7` | **17.51:1** | ✅ 远超 | 正文、标题 |
| `--ink-2 #4A4A4A` | `--paper` | **8.42:1** | ✅ | 次级说明 |
| `--muted #6B6B6B` | `--paper` | **5.06:1** | ✅ | 日期、编号、辅助 |
| `--accent #7A2A34` | `--paper` | **9.04:1** | ✅ | 链接、当前导航 |
| `--on-black #F2F1EE` | `--black #0E0E0E` | **17.09:1** | ✅ | 黑底主文字 |
| `--on-black-2 #A8A6A2` | `--black` | **7.94:1** | ✅ | 黑底次级文字 |
| `--on-black-3 #8A8885` | `--black` | **5.46:1** | ✅ | 黑底最弱文字 |
| `--accent-on-black #C98A92` | `--black` | **6.93:1** | ✅ | 黑底强调 |
| `--muted #6B6B6B` | `--paper-2 #F2F1EE` | **4.72:1** | ✅ | 浅灰区块上的辅助文字 |

**【事实】** 所有文字配色均满足 WCAG AA（≥4.5:1）；正文对比度超过 17:1。
`--rule` 为装饰线（非文字），不适用 AA 文字门槛。

### 2.3 与参考项目的关系【事实 + 建议】

- 【事实】参考项目实测为纯无彩色：近白 `#F4F4F4`、近黑 `#0B0B0B`，无强调色。
- 【建议】本站 `--paper #FAF9F7`（暖白）与 `--black #0E0E0E` 与参考观感一致；
  暗红为任务书要求的识别色，**仅用于链接/当前项/单条细线**，
  面积占比目标 **< 2%**。

## 3. 字体与字号层级

### 3.1 字族【建议】

```css
--serif: "Songti SC", "Noto Serif CJK SC", "Source Han Serif SC",
         "Source Han Serif", "SimSun", Georgia, "Times New Roman", serif;
--sans:  "Helvetica Neue", Arial, "PingFang SC", "Hiragino Sans GB",
         "Microsoft YaHei", system-ui, sans-serif;
```

- **正文（中文）**：宋体系（serif）——贴合诗集/文学刊物阅读质感。
- **大标题（中文）**：宋体，**大字号 + 加宽字距**，字重 normal（中文放大后不必再加粗，
  否则笔画糊）。
- **英文/数字/辅助标签**：无衬线（sans），与中文标题形成对照。
- **【建议】不引用远程 Web Font**（跨平台/离线/隐私/加载）；使用系统字体栈。

### 3.2 字号层级（`clamp()` 响应式）【建议】

| 层级 | 用途 | 桌面 | 移动 | 字距 | 行高 |
|------|------|------|------|------|------|
| Display | 首页身份/大标题 | `clamp(2.6rem,7vw,4.6rem)` | 同左自动 | .04em | 1.06 |
| H1 | 诗歌标题 / 页面标题 | `clamp(1.7rem,3.4vw,2.5rem)` | 自动 | .02em | 1.25 |
| H2 | 区块标题 | `clamp(1.15rem,2vw,1.5rem)` | 自动 | .04em | 1.35 |
| H3 | 小标题 | `1.02rem` | `1rem` | .02em | 1.5 |
| Body | 正文 | `1.0625rem`（17px） | `1.03rem` | 0 | 1.9 |
| Poem | 诗歌正文 | `1.0625rem` | `1.03rem` | .01em | **2.3** |
| Meta | 日期/编号/标签 | `.78rem` | `.76rem` | .12em | 1.6 |
| Label | 英文小标签（大写） | `.66rem` | `.62rem` | .28em | 1.4 |

**【事实】** 正文 17px/1.9 沿用旧站与 Phase 1/2 的阅读习惯；
诗歌正文行高 2.3 与 Phase 2 一致，**不因本轮设计改动正文行距与阅读习惯**（除非另有说明）。

## 4. 布局、栅格与最大宽度

- **阅读栏（`--measure`）**：`42rem`（≈672px），承接旧站 `--wrap`。
  诗歌正文另设更窄的 `--measure-poem`：`38rem`（≈608px），强化留白与每行字数控制。
- **版心（`--frame`）**：`72rem`（≈1152px），用于首页/索引的非对称大版式。
- **栅格**：以 **12 列 + 不对称配比** 为主，常用 **4/8**、**5/7**、**3/9** 分割，
  避免 6/6 等宽。
- **左右留白**：桌面 `clamp(1.25rem,5vw,4rem)`；不对称区块可在某一侧额外留白。
- **断点**：
  - `--bp-sm: 480px`（大屏手机）
  - `--bp-md: 720px`（平板竖屏 / 开始出现双栏）
  - `--bp-lg: 1024px`（桌面，非对称版式完全展开）

## 5. 留白规范

| 场景 | 桌面 | 移动 |
|------|------|------|
| 区块之间（section gap） | `5rem` | `3rem` |
| 标题与正文之间 | `1.4rem` | `1.1rem` |
| 段落之间 | `1.15em` | `1.1em` |
| 诗歌诗节之间 | `1.5em` | `1.4em` |
| 版心上下内边距 | `clamp(2.5rem,6vw,4.5rem)` | `2rem` |

**【建议】** 区块分隔一律用空白，**不使用卡片边框/背景**。

---

## 6. 图片比例【建议】

- 人物/实物照片：**3:4 或 1:1**，黑白或低饱和。
- 宽幅叙事图：**16:9 或 21:9**，可作黑色区的出血底图。
- 小图/缩略：**4:3**。
- 统一 `object-fit: cover`；无授权照片时**不放装饰图**，用纯文字构图。

---

## 7. 标题与正文阅读规范

### 7.1 标题【建议】
- 左对齐（非居中），大字号、宽字距；中文标题**允许换行**，行高 1.2–1.3。
- 英文标签大写、加宽字距，置于中文标题上方或下方作为对照。
- 标题**不加下划线、不加背景色块**（弃用 Phase 2 的黑色标题条）。

### 7.2 正文阅读【建议/硬约束】
- 中文正文左对齐、首行不缩进（现代文学排版），行高 1.9。
- **诗歌正文**：居中或左对齐沿用现有习惯，`white-space: pre-wrap` 保留分行与空行；
  **逐字不改**（见 §9 与 page-design.md）。
- 阅读宽度受 `--measure-poem` 约束，避免单行过长。
- 段间距用 margin，不用空 `<p>`（但**不修改已有内容结构**）。

---

## 8. 交互状态【建议】

| 状态 | 表现 |
|------|------|
| 链接默认 | `--accent`，无下划线 |
| 链接悬停 | 下划线（`text-underline-offset: 3px`） |
| 当前导航 | `--accent`（白底）/ `--accent-on-black`（黑底） |
| 焦点（`:focus-visible`） | `2px solid --accent`，`outline-offset: 2px` |
| 列表项悬停 | 标题转 `--accent`，行左缘出现细强调线（可选） |
| 黑底链接 | `--on-black`，悬停转 `--accent-on-black` |

**【建议】** 过渡仅用 `color`/`border-color`，时长 ≤ 160ms，避免动效喧宾夺主。

---

## 9. 无障碍与内容保护（硬约束）

1. 所有文字配色满足 WCAG AA（见 §2.2）。
2. 保留「跳到正文」跳转链接与语义化地标（`header/main/nav/footer`）。
3. 触控目标 ≥ 44×44px。
4. **不得**因模板调整改变任何诗歌正文、作者小传、题记、档案记录的文字与结构。
5. 审阅门禁（`/review/` 令牌）逻辑**完全不动**。
