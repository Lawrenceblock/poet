# Phase 3 · 设计研究：Ammons Poems Website（Tubik）

> 本文件是「安然诗歌档案」第三轮视觉设计（Editorial Design 方向）的研究底稿。
> 目的是把参考项目 Ammons Poems Website 的**现代主义编辑设计语言**研究清楚，
> 再转化为适合中文诗歌与数字文学档案的视觉体系。
>
> 约定：全文严格区分 **【事实】**（可核实）、**【推断】**（基于图像的合理判断）、
> **【建议】**（为本站提出的转化方案）。凡未能核实的，一律标注，不虚构。

### 1.3 本地图像分析方法（可复现）

对下载的参考图做了两类程序化分析，避免主观臆断：

- **色彩**：降采样后统计精确十六进制频次，并计算每个像素的色度（`max−min` 通道差），
  以判定是否存在「强调色」。
- **构图**：转灰度后按网格采样，输出明暗结构图（`#` 暗 / `.` 亮 / `+` 中间调），
  并做行/列方向的暗像素密度剖面，用于判断非对称与留白。

## 2. 项目背景（来自 S1 官方正文）【事实】

- 纪念对象：**Archibald Randolph Ammons**（A. R. Ammons），20 世纪美国诗人、
  康奈尔大学英文教授，出版约 30 部诗集，两度获美国国家图书奖（1973、1993）。
- 核心内容物：长诗 **《Tape for the Turn of the Year》**。1963-12-06，诗人把一卷
  加法机纸带装进打字机，写下「我决定写一首又长又细的诗」，由此成为一首书体长诗。
  原稿纸带（约 52 米）与手稿现存康奈尔大学图书馆珍本与手稿部。
- 设计团队：Oksana Lashko、Vlad Taran、Natalka Mamchur、Olga Syrotkina。
- 官方对整体风格的描述（原文）：
  > "a minimalistic approach with an ultra-limited color palette, bold typography,
  > creative asymmetry, and solid visual hierarchy, allowing the arrangement of
  > text blocks in an elegant way."

  即：**极简、极受限的色彩、粗体排版、创造性非对称、稳固的视觉层级**。
- 长诗阅读体验的三个模式：**手稿模式 / 排印（数字文本）模式 / 对照模式**；
  另有进度追踪、日期标注、分享、明暗背景切换等交互。
- **诗歌页起始屏刻意用深色背景**，与其余「明亮、通透」的页面形成对照，
  并配打字机照片（该照片正是诗人本人的那台打字机）。

## 3. 色彩体系

### 3.1 参考项目的实测色彩【事实】

对 6 张参考图做精确采样（降采样 400×300）：

| 页面 | 主色（近白） | 主色（近黑） | 是否存在强调色 |
|------|--------------|--------------|----------------|
| 首页 | `#F5F5F5` `#F2F2F2` | `#181818` `#171717` | 无（色度=0） |
| 传记页 | `#F4F4F4` `#F2F2F2` | `#0C0C0C` `#0B0B0B` | 无 |
| 诗歌传承页 | `#F4F4F4` `#F2F2F2` | `#0B0B0B` | 无 |
| 诗歌页起始（深色） | 极少 | `#0A0A0A`–`#0E0E0E` | 无 |
| 手稿模式 | 极少 | `#0B0B0B`（49%） | 无（暖褐来自纸带照片） |
| 移动端 | `#F5F5F5` | `#171717`–`#1F1F1F` | 无 |

**关键结论【事实】**
1. 参考项目是**纯无彩色（achromatic）**体系：所有 UI 颜色色度为 0，
   即真正意义上的黑—白—灰，**没有任何品牌强调色**。
2. 唯一的「色彩感」来自**摄影素材本身**：
   - 纸带/手稿照片呈现暖褐（`#DBC49B`，色度 64）——历史纸张的天然色调；
   - 打字机照片呈现冷蓝灰（`#43485E` 一带）——照片本身的冷调。
   也就是说，**温度来自照片，而不是来自界面配色**。
3. 深色区（诗歌页）比浅色区的「黑」更深：浅色页的墨色约 `#0B–#18`，
   深色页背景约 `#0A–#0E`。两者接近，可视为同一「墨黑」。

### 3.2 对本站的转化【建议】

- 采用 **黑 / 白 / 灰**为绝对主体，`--paper` 用略带暖度的近白（见 design-system.md），
  与参考的 `#F4F4F4` 观感一致但更适合长时间中文阅读。
- **暗红（`#762B35` 系）只作为极小面积的识别色**：链接、当前导航、单条细分隔线、
  极少数强调词。**不得**成为区块背景、标题条底色或大面积装饰。
  （对照：参考项目连这一点都没有；本站保留暗红是任务书的明确要求，
  因此把它压到最低可感知强度。）
- 深色区（黑）在参考中用于**诗歌阅读起始屏**与照片叙事。本站转化时：
  黑色用于**首页主视觉、页脚、诗歌页页头**这三处「结构节点」，
  其余一律纸白，形成「黑为骨、白为诗」的节奏（与 Phase 2 的差别见 §8）。

## 4. 字体体系

### 4.1 参考项目【事实 + 推断】

- **【事实】** 官方描述为 "bold typography"。Dribbble 稿中，作者姓名
  （ARCHIBALD AMMONS / A. R. AMMONS）使用**大字号、无衬线、字重偏粗**的字样，
  常以单行横跨版面，字号与正文字号拉开极大差距。
- **【事实】** 正文/辅助信息字号明显小于标题，元信息（日期、分类）字号最小。
- **【推断】** 英文正文为无衬线或中性衬线，行距宽松；标题靠**字号与字重**建立层级，
  而非靠颜色或装饰。
- **【推断】** 标题常与图片、色块形成非对称的对齐关系（左对齐为主，非居中）。

### 4.2 中文字体转化的难点【事实/推断】

- **【事实】** 中文没有「无衬线大写字母」这种强化手段，且汉字字形方正，
  单纯把英文字号放大到跨版，会造成**字距过密、笔画拥挤、行首行尾参差**。
- **【推断】** 中文标题的冲击力应来自：**大字号 + 充分字距（letter-spacing）+
  克制的字重 + 大量留白**，而不是无限放大。
- **【建议】** 中文正文用**宋体系（serif）**以承袭「诗集/文学刊物」的阅读质感；
  中文标题可尝试**宋体大字号 + 加宽字距**，英文/数字用无衬线或中性衬线作对照。
  字体的**可用性、跨平台兼容**优先（见 design-system.md §字体）。

## 5. 页面布局与非对称构图

### 5.1 实测结构【事实】

对首页、传记页、诗歌传承页做明暗结构图分析，得到稳定模式：

- **首页**：上方为大面积黑色区（约占上部 1/4～1/3，含作者名/主视觉），
  下方为纸白区，内容块**左对齐、宽窄不一**，右侧留白明显多于左侧，
  呈**左重右轻的非对称**。
- **传记页**：**左侧一列窄栏**（文字/说明）+ **右侧大块图像或文字**，
  两栏宽度不等，中间以竖直白缝分隔（结构图中可见连续的空列）。
- **诗歌传承页**：左侧一个**黑色竖条/窄栏**贯穿，右侧为纸白内容，
  形成「黑柱 + 白场」的强对照。

### 5.2 非对称手法归纳【事实 + 推断】

1. **不等宽栏**：常见 1:2 或 1:3 的宽窄对比，而非等宽双栏。
2. **黑块作为版面「重物」**：一块实心黑（或大图）压在一侧，另一侧留白。
3. **标题跨栏**：大标题可以越过常规内容栏宽度，甚至延伸到页边。
4. **对齐锚点**：内容多沿左对齐或某条隐形竖线对齐，制造秩序感。
5. **留白即结构**：区块之间用大段空白分隔，而非分隔线或卡片边框。

### 5.3 转化到本站【建议】

- 首页改为**左重右轻的非对称**：左侧大字号站名/身份 + 右侧图像或留白，
  下方内容块**左对齐、宽度不一**（如「最新作品」窄栏、「按年份」宽栏交错）。
- 索引页（卷目/年份）用**大字号年份 + 细线 + 编号**，年份与作品列表不等宽。
- **取消** Phase 2 的「黑色栏目标题条」这种等宽卡片式单元（见 §8）。

## 6. 图片与摄影

### 6.1 参考项目【事实】

- 图片以**黑白/低饱和人物与实物照片**为主：诗人肖像、打字机、手稿纸带、书封。
- 官方强调：诗歌页起始屏的打字机照片**是诗人本人的那台真实打字机**，
  具有叙事与情感价值（"not a random image"）。
- 图片与文字的关系：**图文并置、非对称**，图像承担叙事，文字承担信息。

### 6.2 版权约束与本站策略【事实 + 建议】

- **【事实】Tubik 案例页页脚声明**：
  > "The text and graphic content of the website belongs to Tubik and cannot be
  > used by other resources without our permission and without the link to the source."
- **【建议】本站严格不复制** Ammons 网站的人物照片、打字机照片、手稿图或任何
  Tubik 商业素材。参考项目仅作为**设计语言**的学习对象。
- **【建议】图片来源优先级**：
  1. 作者授权/提供的照片；
  2. 原创生成的抽象视觉、历史空间意象、非真实人物身份的图像；
  3. **没有合适图片时，保留纯文字构图**，不为填满版面而添加装饰图片。
- **【建议】** 若未来使用作者照片，采用**黑白/低饱和**处理以贴合编辑设计语言；
  处理前需作者明确授权，且**不得**把他人照片当作安然本人。

## 7. 留白规律

### 7.1 参考项目【事实 + 推断】

- **【事实】** 实测首页/传记页：亮色（纸白）占比约 **45%–55%**，深色占比 15%–40%，
  中间调极少——说明**大块纯色 + 大块留白**，而非细碎纹理。
- **【推断】** 区块间距显著大于行距；内容不铺满整行，右侧常留出宽白。
- **【推断】** 文字密度克制：每屏信息量少，靠留白与层级引导阅读。

### 7.2 转化【建议】

- 正文阅读栏宽度适中（不追求满屏），左右留白充分。
- 区块之间用**空白**分隔，而不是边框、阴影、卡片。
- 诗歌正文页：**纸白为主，黑色仅出现在页头窄带与页脚**，正文周围留白最大化。

## 8. 桌面端与移动端差异

### 8.1 参考项目【事实 + 推断】

- **【事实】** 存在独立的移动端设计稿（Dribbble shot #3、官方移动端配图）。
- **【推断】** 移动端把**非对称双栏压成上下堆叠**；黑块与图像置于内容上方；
  导航收敛为紧凑形式；正文阅读宽度自适应，保持宽松行距。

### 8.2 转化【建议】

- **移动端必须单独设计**，不是把桌面端等比缩小：
  - 中文大标题**允许换行**，字距随之调整，避免单行溢出；
  - 图像与文字**上下排列**，图像在上；
  - 导航在窄屏**收敛为紧凑横向或可展开**形式；
  - 诗歌正文**限制阅读宽度**（约 20–24 个汉字/行）并放大行距；
  - 触控目标不小于约 44×44px。

## 9. 可借鉴的部分【建议】

1. **纯黑白灰 + 摄影提供温度**的配色哲学。
2. **创造性非对称**：不等宽栏、黑块配重、标题跨栏。
3. **bold typography**：以字号/字重/字距建立层级，不靠颜色与装饰。
4. **负空间优先**：留白作为主要分隔手段，弃用卡片与阴影。
5. **阅读页的「黑—白」对照**：深色起始屏 → 明亮正文（本站转化为
   黑色页头窄带 → 纸白正文）。
6. **长读体验**：进度/年代/分节的可读结构（本站对应「卷目 / 年份 / 创作日期」）。

## 10. 不适合直接迁移的部分【建议】

1. **英文大字跨版**：中文不能照搬，否则拥挤、断行难看（见 §4.2）。
2. **纯无强调色**：本站任务书要求保留少量暗红识别色——但必须极克制。
3. **人物照片叙事**：本站暂无授权照片，且版权受限，**以纯文字构图为主**。
4. **手稿/纸带照片**：Ammons 独有素材，不可复制，也不能伪造类似实物图。
5. **三模式长读交互（手稿/排印/对照）**：属该站特定内容形态，本站无对应物，
   仅借鉴其「长读节奏」理念，不照搬交互。
6. **等宽卡片列表**：参考项目并不使用卡片；本站也不应退回卡片式布局。

## 11. 与本站 Phase 2 的关系

- **【事实】** Phase 2（commit `6c9bd55`）采用「黑色骨架」：黑色页眉、黑色主视觉、
  **黑色栏目标题条**切分白色内容区、黑色页脚。
- **【事实】** 作者对 Phase 2 最终效果不满意（任务书陈述）。
- **【建议】** Phase 3 不再沿用「黑色栏目标题条」这一等宽卡片式单元；
  改为参考项目的**非对称、负空间、字号层级**手法。
  黑色仍是重要空间，但从「标题的背景色」升格为**整个版面的一块空间区域**。

## 12. 研究结论（一句话）

> Ammons 项目的本质不是「黑白色」，而是一套**极简编辑设计方法**：
> 极受限的无彩色、以字号与字重建立层级、创造性非对称、用摄影提供温度、
> 用负空间代替装饰。Phase 3 要转化的是这套**方法**，
> 而非它的颜色、照片或具体版式；并针对中文诗歌的阅读习惯重新适配。
