# 第二轮视觉设计实施说明（POET-VISUAL-REFINEMENT-02）

主题：**黑色骨架、白色空间、暗红细节**。
基线：`design/phase1-visual-refinement-2026-11-13` @ `b73178c`。
分支：`design/phase2-black-white-composition-2026-11-13`。

本说明在动手前先厘清结构，随后据此实施。

---

## 一、现状审查（第一轮成果）

| 页面 | 现状 | 本轮问题 |
| --- | --- | --- |
| 首页 | 白底 + 灰色细线区块 | 无黑色主视觉；层次全靠灰线，缺乏力量 |
| 诗歌正文 | 白底墨黑，标题下短灰线 | 阅读体验好，**保留**；缺黑色元数据结构 |
| 卷目 / 年代索引 | 白底 + 细分隔线列表 | 无黑色年份/栏目标题单元，节奏平 |
| 档案说明 / 小传 | 白底长文 | 无黑色栏目标题 |
| 搜索 | 白底表单 | 无黑色标题条 |
| 作者审阅 | 白底 + 暗红强调 | 无黑色页头，与公开页缺乏统一骨架 |
| 移动端导航 | 单行流式换行 | 需在黑色页眉内重新优化，避免拥挤/重叠 |

**结论**：第一轮解决了配色（去蓝、改白），但**未建立黑色结构**。本轮不推翻白色阅读体系，而是补上黑色骨架。

## 二、色彩规范（本轮明确黑白比例）

| 用途 | 色值 | 变量 | 备注 |
| --- | --- | --- | --- |
| 主要黑色区域 | `#171717` | `--black` | 页眉 / 主视觉 / 栏目标题条 / 页脚 |
| 正文深色文字 | `#242424` | `--ink` | 白底正文 |
| 主要白色空间 | `#FFFFFF` | `--bg` | 诗歌阅读 |
| 次级暖白背景 | `#F7F6F4` | `--bg-soft` | 说明块等 |
| 暗红强调 | `#762B35` | `--accent` | **白底上**的链接/强调 |
| 辅助灰色（白底） | `#757575` | `--muted` | 由 `#777777` 调整，达 AA（4.61:1） |
| 分隔线 | `#E2E0DE` | `--rule` | 白底细线 |
| 黑色区域上的次级文字 | `#A0A0A0` | `--on-black-muted` | 黑底 6.86:1 |
| 黑色区域上的当前项 | `#CB6E77` | `--on-black-accent` | 暗红的**黑底可读**衍生色，5.15:1 |

**关于暗红**：规范色 `#762B35` 在黑底上对比度仅 1.85:1，几乎不可见。
因此黑色区域内改用同色相的提亮衍生色 `#CB6E77`（视为「暗红细节」在深色底的呈现）。
白底上仍严格使用 `#762B35`。此决定记录于风险说明，供作者确认。

## 三、黑色骨架体系（页眉 / 栏目 / 页脚三位一体）

```
┌──────────────────────────────────────────────┐
│  黑色页眉 #171717                              │
│   安然诗歌档案   ANRAN POETRY ARCHIVE          │  白字 + 小字英文标识
│   卷目 · 年份 · 题记 · 小传 · 档案说明 · 搜索   │  浅灰导航；当前项暗红
├──────────────────────────────────────────────┤
│  黑色主视觉（仅首页）#171717                   │
│   封面图 + 站名 + 英文 + 定位 + 说明            │
├──────────────────────────────────────────────┤
│  白色内容区 #FFFFFF                            │
│   ▐ 黑色栏目标题条（白字）                      │  ← 作品 / 年份 / 档案 等
│   白色条目 / 白色正文                           │
│   ▐ 黑色栏目标题条                              │
│   白色条目                                      │
├──────────────────────────────────────────────┤
│  黑色页脚 #171717                              │
│   站名 + 简介 + 栏目入口 + 版权 + 档案声明       │
└──────────────────────────────────────────────┘
```

黑色区块只出现在**有结构意义**的位置：页眉、首页主视觉、栏目标题、页脚。
正文与条目一律留在白色空间。形成「黑—白—黑—白」的节奏。

## 四、逐页处理

| 页面 | 增加的黑色区域 | 保持白色 | 暗红用量 |
| --- | --- | --- | --- |
| 首页 | 页眉 + **主视觉区** + 4 个栏目标题条 + 页脚 | 作品列表、年份、入口、说明 | 当前导航、栏目标题条左缘 |
| 诗歌正文 | 页眉 + 页脚 + **黑色元数据条**（作品编号/日期/作者） | **诗歌正文全白** | 返回链接 |
| 卷目 | 页眉 + 黑色年份标题条 + 页脚 | 作品条目 | 当前年份标记 |
| 年代索引 | 页眉 + 黑色年份标题条 + 页脚 | 作品条目 | 年份跳转当前项 |
| 档案说明 / 小传 | 页眉 + 黑色栏目标题条 + 页脚 | 正文长文 | 链接 |
| 搜索 | 页眉 + 黑色栏目标题条 + 页脚 | 表单与结果 | 链接 |
| 作者审阅 | 页眉（同款黑色条）+ 页脚式黑色底注 | 审阅表单与诗歌副本 | 按钮、选中态 |

## 五、桌面端与移动端

- **页眉**：桌面端为「左站名 + 右导航」的黑色横幅；移动端上下堆叠，
  站名居中、导航一行居中换行，`padding` 加大，避免拥挤与重叠。
- **主视觉**：桌面端封面图与文字并排（左右分栏）；移动端上下堆叠，封面图居中。
- **栏目标题条**：全宽黑条，桌面端文字较大，移动端保持同一识别度但不换行溢出。
- **页脚**：桌面端多栏；移动端单列堆叠。
