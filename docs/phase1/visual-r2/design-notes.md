# 第二轮视觉设计说明（POET-VISUAL-REFINEMENT-02）

主题：**黑色骨架、白色空间、暗红细节**。
基线：`design/phase1-visual-refinement-2026-11-13` @ `b73178c`。
分支：`design/phase2-black-white-composition-2026-11-13`。

本轮是**整页构图优化**，不是换色。第一轮解决了「去蓝、改白」，
但结构仍由灰色细线支撑，块面力量不足。本轮补上**黑色骨架**。

---

## 一、设计原则

1. **黑色只用在有结构意义的位置**：页眉、首页主视觉、栏目标题、页脚。
2. **白色留给阅读**：诗歌正文、条目列表、表单始终在白底上。
3. **暗红是细节，不是主角**：只用于当前项、链接、标题条左缘、按钮。
4. **黑白交替形成节奏**：页眉（黑）→ 主视觉（黑）→ 内容（白，被黑标题条切分）→ 页脚（黑）。

## 二、配色规范

| 用途 | 色值 | 变量 | 黑/白底对比度 |
| --- | --- | --- | --- |
| 主要黑色区域 | `#171717` | `--black` | — |
| 正文深色文字 | `#242424` | `--ink` | 白底 15.52:1 |
| 主要白色空间 | `#FFFFFF` | `--bg` | — |
| 次级暖白背景 | `#F7F6F4` | `--bg-soft` | — |
| 暗红强调（白底） | `#762B35` | `--accent` | 白底 9.69:1 |
| 暗红强调（黑底） | `#CB6E77` | `--on-black-accent` | 黑底 5.15:1 |
| 辅助灰（白底） | `#757575` | `--muted` | 白底 4.61:1（AA） |
| 黑底次级文字 | `#A0A0A0` | `--on-black-muted` | 黑底 6.86:1 |
| 黑底主文字 | `#FFFFFF` | `--on-black` | 黑底 17.93:1 |
| 分隔线 | `#E2E0DE` | `--rule` | — |

**关于暗红（重要）**：规范色 `#762B35` 在黑底上对比度仅 1.85:1，几乎不可见。
因此黑色区域内改用同色相提亮衍生色 `#CB6E77`（视为「暗红细节」在深色底的呈现，黑底 5.15:1，达 AA）。
白底上仍严格使用 `#762B35`。此决定记录于 `changes-and-risks.md`，供作者确认。

## 四、桌面端与移动端

- **页眉**：桌面端「左站名 + 右导航」的黑色横幅；移动端上下堆叠、居中换行，
  加大 `padding`，避免拥挤与重叠。320px 宽度下无横向溢出。
- **主视觉**：桌面端封面图与文字左右分栏；移动端上下堆叠、封面居中。
  封面 PNG 透明率 68%，边缘与黑底自然融合，无方框痕迹。
- **栏目标题条**：全宽黑条，白字 + 左缘暗红细线；桌面/移动同一识别度。
- **页脚**：桌面端多栏；移动端单列堆叠，黑底浅灰字。

## 五、与第一轮的关系

- **保留**：白色阅读体系、衬线字体栈、诗歌行高与阅读宽度、方角标签、无外部依赖。
- **新增**：黑色页眉 / 主视觉 / 栏目标题条 / 页脚、黑色诗歌页头、黑色章节标题。
- **替换**：原「白底 + 灰色细线」的区块分隔，改为黑色标题条切分白色内容。
- 辅助灰由 `#777777`（4.48:1）调整为 `#757575`（4.61:1），达 WCAG AA——
  这正是第一轮报告中列为「待作者确认」的微调项，本轮一并落实。
