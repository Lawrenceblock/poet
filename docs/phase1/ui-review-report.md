## 3. 发现的问题（【已验证】）

1. **标题实体双重转义（真实缺陷，影响 1 篇）**
   - 候选 C0013 标题含 HTML 实体 `&#39;`。审阅页直接输出为 `&amp;#39;`，浏览器显示成字面量 `&#39;`。
   - 受影响页面：`/review/index.html`、`/review/batch-B-1.html`、`/review/poem/C0013.html`（共 3 个页面、4 处）。
   - 属于**展示层转义**问题；**诗歌正文未受影响，保持逐字不变**。
   - 建议：审阅页渲染标题时先解码再转义（正文渲染路径不动，以保护逐字保真）。

2. **移动端断点偏少（【建议】）**
   - 仅 480px 一个断点。诗歌页 `line-height: 2.4` 在窄屏略大（已降到 2.2）。
   - 建议：在候选阶段用真机核对 375 / 414 / 768px 三档。

3. **搜索为纯前端（【已验证】）**
   - 无 JS 时提示“站内搜索需要启用 JavaScript”。索引仅 6 条样例。
   - 建议：候选阶段先保证无 JS 时给出静态卷目入口，避免“空搜索”。

4. **生产 robots.txt 允许抓取（【已验证】）**
   - 正式域名下 `Allow: /`；非正式域名下 `Disallow: /`（模板按 host 判断）。
   - 提醒：候选站挂在临时域名上，属 `Disallow: /`，**不会被搜索引擎收录**，符合作者私密审阅预期。
