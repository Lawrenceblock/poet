# 视觉候选 · 设计规范（Design System）

> 实施依据 `design-notes.md`。本文件给出可执行的变量与规则。
> 变量实现于 `hugo/assets/css/style.css` 的 `:root`。

---

## 1. 色彩变量

```css
:root {
  --paper:          #FAF9F7;  /* 页面主背景（暖白） */
  --paper-2:        #F2F1EE;  /* 次级底 / 浅灰区块 */
  --ink:            #141414;  /* 主文字 */
  --ink-2:          #4A4A4A;  /* 次级文字 */
  --muted:          #6B6B6B;  /* 辅助文字（日期/编号） */
  --black:          #0E0E0E;  /* 结构黑（首页主视觉 / 诗歌页头 / 页脚） */
  --on-black:       #F2F1EE;
  --on-black-2:     #A8A6A2;
  --on-black-3:     #8A8885;
  --rule:           #DAD8D4;  /* 细分隔线 */
  --rule-strong:    #C4C1BC;
  --rule-on-black:  #2A2A2A;
  --accent:         #7A2A34;  /* 暗红：链接/当前项/小标签/单条细线 */
  --accent-on-black:#C98A92;  /* 暗红衍生（黑底可读） */
}
```

### 对比度（WCAG 实测）

| 前景 | 背景 | 比值 | AA 正文 4.5:1 |
|------|------|------|----------------|
| `--ink` #141414 | `--paper` #FAF9F7 | **17.51:1** | ✅ |
| `--ink-2` #4A4A4A | `--paper` | **8.42:1** | ✅ |
| `--muted` #6B6B6B | `--paper` | **5.06:1** | ✅ |
| `--accent` #7A2A34 | `--paper` | **9.04:1** | ✅ |
| `--on-black` #F2F1EE | `--black` #0E0E0E | **17.09:1** | ✅ |
| `--on-black-2` #A8A6A2 | `--black` | **7.94:1** | ✅ |
| `--on-black-3` #8A8885 | `--black` | **5.46:1** | ✅ |
| `--accent-on-black` #C98A92 | `--black` | **6.93:1** | ✅ |
| `--muted` #6B6B6B | `--paper-2` #F2F1EE | **4.72:1** | ✅ |

`--rule`（1.35:1）为装饰线，不适用文字门槛。暗红面积占比目标 **< 2%**（实测各页 0.01–0.7%）。

## 2. 字体

```css
--serif: "Songti SC", "Noto Serif CJK SC", "Source Han Serif SC",
         "Source Han Serif", "SimSun", Georgia, "Times New Roman", serif;
--sans:  "Helvetica Neue", Arial, "PingFang SC", "Hiragino Sans GB",
         "Microsoft YaHei", system-ui, -apple-system, sans-serif;
```

- 中文正文与标题：**宋体系**（诗集/文学刊物阅读质感）。
- 英文/数字/小标签：**无衬线**（与中文标题形成对照）。
- **不引用远程 Web Font**（跨平台/离线/隐私/加载）。

## 3. 字号层级（`clamp()` 响应式）

| 层级 | 用途 | 桌面实测 | 字距 | 行高 |
|------|------|----------|------|------|
| Display | 首页主标题 | 67.2px | .06em | 1.08 |
| H1 | 页标题 | 48px | .05em | 1.18 |
| H1 | 诗歌标题 | 41.6px | .05em | 1.28 |
| H2 | 区块标题 | ~24px | .1em | — |
| 年份数字 | 卷目/年份/首页 | 49.6px / 38.4px | .05em | 1 |
| Body | 正文 | 17px | 0 | 1.9 |
| Poem | 诗歌正文 | 17px | 0 | **2.3** |
| Meta | 日期/编号 | .76rem | .12em | 1.6 |
| Label | 英文小标签 | .66rem | .3em+ | 1.4 |

移动端：主标题 36.8px，诗歌标题 27.2px，页标题 30.4px；诗歌正文 16.5px / 行高 2.25。

## 4. 布局与最大宽度

| 变量 | 值 | 用途 |
|------|----|------|
| `--frame` | 72rem (1152px) | 版心：页眉、页头、首页栅格、卷目外框 |
| `--measure` | 42rem (672px) | 说明/题记长文、搜索表单与结果 |
| `--measure-poem` | 36rem (576px) | 诗歌正文栏 |
| `.index` 限宽 | 52rem (832px) | 卷目/年份列表 |
| `--pad` | `clamp(1.25rem, 5vw, 4rem)` | 左右留白 |
| `--section-gap` | `clamp(3rem, 6vw, 5rem)` | 区块间留白 |

- 版心**左缘对齐**：页头大标题与内容块共享同一左缘，右侧留白，形成非对称。
- 首页内容块栅格：桌面 `5fr / 7fr` 交错（实测宽 400 / 560px）；≤860px 单列堆叠。
- 断点：480px（大屏手机）、760px（页眉转横排）、860px（首页双栏展开）。

## 5. 组件规则（无卡片、无阴影、无圆角）

- **页眉**：纸白 + 底部 1px `--ink` 细线；当前项用暗红下划线。
- **页头**：纸白 + 底部 1px `--rule`；小标签暗红，标题墨黑。
- **诗歌页头**：黑底窄带；小标签 `--accent-on-black`，标题 `--on-black`，元信息 `--on-black-2/3`。
- **区块标题**：上方 2px 墨黑细线 + 左对齐标题 + 右侧英文小标签（取代黑色标题条）。
- **列表**：`--rule` 细分隔线，编号/日期用 `--muted` 无衬线小字。
- **搜索输入**：仅下边框（2px 墨黑），聚焦转暗红；无圆角、无阴影。
- **页脚**：黑底结构节点；栏目索引 + 版权。
- **页脚以上一切**：无卡片、无阴影、无渐变、无玻璃拟态、无胶囊标签堆叠。

## 6. 无障碍

- 全部文字配色 ≥ WCAG AA（正文 17.51:1）。
- 移动端导航触控高度 **44px**（实测 nav link 高 44px）。
- `:focus-visible` 2px 暗红描边。
- `skip-link` 跳到正文；`prefers`/打印样式隐藏导航与页脚。
- 无横向溢出（桌面与移动端 `scrollWidth == innerWidth`，实测 0 溢出）。
