# 视觉候选 · 设计说明（Visual Final）

> 分支 `design/poet-visual-final-2026-11-13`，基线 `1037d1b`（第三轮 Ammons/Tubik 编辑设计）。
> 参考：`docs/phase3-ammons/research.md`（Ammons/Tubik 设计语言研究）。
> 本文件说明**相对第三轮实际改了什么、为什么**，以及**与参考案例的对应关系**。

## 1. 本次的判断依据（先看真实页面，再决定是否改动）

按任务书 Phase C，先构建第三轮并**实测页面**（DOM 几何、计算样式、像素构成），
而不是只读设计说明。实测发现第三轮的主要问题：

| 现象（实测） | 数据 |
|--------------|------|
| 首页「黑」过多，主视觉区出现大片空黑 | 首页桌面黑像素 **51.6%**；主视觉文本在 y=272 结束，而 hero 延伸到 ~y=610 |
| 全站黑色节点偏多 | 顶栏、首页主视觉、每个内页页头、诗歌页头、页脚**都是黑** |
| 诗歌页头黑带偏高 | 诗歌页黑 44.4%，页头占据较多首屏 |
| 内容列偏窄且居中 | 阅读栏居中，版心两侧留白对称，非对称感弱 |
| 中文大标题字距在移动端偏松 | 桌面 73.6px / 0.04em 合适；但整站黑底使「字号层级」不易被感知 |

结论：第三轮方向（Ammons/Tubik 编辑设计）正确，但**黑色的面积与分布**、以及
**内页的版式一致性**需要完善。本轮不改内容，只调结构比例与版式。

## 2. 本轮的五项改动

### 2.1 黑色收敛为「两个时刻」，其余为纸白

- **顶栏**：由「窄黑带」改为**纸白 + 细线**的刊物页眉（站名在左、导航在右）。
- **内页页头**（卷目 / 年份 / 说明 / 题记 / 搜索 / 404 / 列表）：由黑色改为**纸白编辑版式**，
  用「细线 + 大标题 + 暗红小标签」建立层级。
- **保留黑色**只用于两处「阅读/身份时刻」：
  1. **首页主视觉**（身份与档案气质）；
  2. **诗歌正文页页头**（承接参考案例「深色起始屏 → 明亮正文」的对照）。
  另加**黑色页脚**作为结构收束。

效果（实测黑像素占比）：首页 51.6% → **44%**；卷目 44.4% → **24%**；
说明 28.9% → **17%**。诗歌页仍保留黑页头（44.4% → 38%），维持「黑—白」对照。

### 2.2 首页主视觉：有边界的黑块，不再撑满屏幕

- 主视觉高度由「接近满屏」改为**内容驱动**（桌面实测 492px，约占首屏 55%）。
- 移除封面图位（原为占位/概念图，非授权摄影），改为**纯文字构图**。
- 新增底部一行**档案数据**（收录篇数 / 年份数 / 最近更新），右对齐，
  与左侧大标题形成**左重右轻的非对称**，并让黑色区有实质信息而非空场。

### 2.3 内页改为「共享版心左缘」的左对齐编辑版式

- `.wrap` 版心由「窄居中」改为与页头大标题**同一条左缘**（`--frame` 72rem），
  内容块各自限宽，右侧留白——即参考案例的「左对齐锚点 + 右侧负空间」。
- 卷目 / 年份列表限宽 52rem；说明与题记正文限宽 `--measure`（42rem）。

### 2.4 中文标题的字号 / 字距 / 字重

- 首页主标题：`clamp(2.3rem, 6.6vw, 4.2rem)`，字距 `.06em`，字重 normal（宋体放大后不再加粗）。
- 诗歌标题：`clamp(1.7rem, 4.2vw, 2.6rem)`；页标题：`clamp(1.9rem, 4.6vw, 3rem)`。
- 移动端字距相应收紧（`--hero-title` 0.04em），避免单行溢出与字距过松。

### 2.5 诗歌正文：更窄的阅读栏

- `--measure-poem` 由 38rem 收紧到 **36rem**（桌面实测正文栏 576px，约 24–26 汉字/行），
  行高保持 **2.3 不变**，正文逐字不变。

## 3. 与 Ammons/Tubik 参考案例的对应关系

| 参考案例（Tubik） | 本站转化 |
|-------------------|----------|
| 极受限的无彩色（黑/白/灰，无强调色） | 纸白 `#FAF9F7` / 墨黑 `#141414` / 结构黑 `#0E0E0E`；暗红仅作识别色（<2% 面积） |
| bold typography：以字号/字重/字距建层级 | 中文宋体大字号 + 宽字距 + normal 字重；英文/数字用无衬线对照 |
| 创造性非对称（不等宽栏、黑块配重） | 首页主视觉左重右轻 + 档案数据右对齐；内容块 5/7 交错（实测 400/560px） |
| 大面积负空间 | 区块以空白分隔，弃用卡片/阴影/边框块 |
| 诗歌页「深色起始屏 → 明亮正文」 | 诗歌页黑色页头窄带 → 纸白正文，最大化留白 |
| 温度来自摄影，不来自界面配色 | 无授权照片，故**纯文字构图**，不引入装饰图片 |
